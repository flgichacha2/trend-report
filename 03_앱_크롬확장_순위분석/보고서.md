# 03. 앱 순위(앱스토어·구글플레이) + 크롬 웹스토어 확장 분석 보고서

- 작성일: 2026-10-09 (수집일 기준 1회 스냅샷)
- 핵심 질문: **"최근 사람들이 자주 쓰는 프로그램은 무엇이고, 쓰면서 무엇에 불만인가?"** → 크롬 확장 사업 아이디어로 연결

---

## ① 핵심 요약 (5줄)

1. **AI 비서 3종이 한국 상위권에 고정 진입**: 구글플레이 한국 무료 전체 2위 ChatGPT, 7위 Claude. 앱스토어 한국 무료 전체에서는 Claude 7위, Gemini 11위, ChatGPT 15위이고, 생산성 카테고리 1~4위는 TeraBox·Claude·Gemini·ChatGPT. 앱 이름 기준으로 AI 키워드가 붙은 앱이 수집한 Top100 차트에 한국 159개, 미국 177개 있었다.
2. **새로 뜨는 앱 유형 (출시 12개월 이내인데 Top100에 든 앱 기준)**: ▲숏폼 드라마(NetShort, DramaBox Lite, BlinkDrama 등. 한국 엔터테인먼트 23개) ▲AI 영상·사진 생성(Dance AI, PixVerse 등) ▲감성·필름 카메라(한국 유료 Top100 중 29개가 1년 내 출시이고 대부분 카메라 앱) ▲AI 학습(유니브 AI, AI 튜터) ▲AI 쇼핑비서(쇼포트) ▲숏폼 차단(SocialLite).
3. **불만 1~3위는 앱·크롬 모두 같다**: 저평점 리뷰에서 가장 많은 유형은 '오류·버그'이고, 그다음이 '업데이트·UI 개악', 그다음이 '결제·구독·환불'(크롬에서는 '기능 부족'). 결제 불만은 숏폼 드라마(DramaBox는 1~2점 197건 중 109건)와 AI 구독 앱(유니브 AI 149건 중 73건)에 몰려 있다.
4. **크롬 웹스토어의 신규 확장 흐름은 'AI 채팅 보조도구'**: 최근 1년 사이 등록된 확장 62개 중 AI 관련이 21개다. 사용량 모니터, 대화 내보내기, 폴더 정리처럼 ChatGPT·Claude·Gemini를 보조하는 확장이 계속 생긴다. 공식 확장의 평점은 낮아서 ChatGPT(600만 사용자)가 2.78점, Claude(1,800만 사용자)가 2.87점이다. 불만은 연결 끊김, 세션·권한 문제다.
5. **앱으로는 뜨는데 브라우저(크롬) 쪽은 비어 있는 기능**: 한국어 강의·회의 녹음 요약('녹음 회의록' 검색 상위 확장은 모두 사용자 5천 명 이하), 쿠팡·네이버 가격 추적('쿠팡 가격 추적기' 계열은 수백 명 수준), 광고 없는 HWP 뷰어, 숏폼 차단·집중 도구, 한국 OTT 이중자막. 이 영역이 크롬 확장 아이디어의 우선 후보다.

## ④ 인사이트 및 크롬 확장 사업 아이디어

### 인사이트
1. **이제 수요는 'AI 그 자체'가 아니라 'AI를 특정 일에 붙이는 것'이다.** 앱 신규 상위권은 간호사 AI, 강의 녹음 AI, 쇼핑 AI, 칼로리 AI처럼 상황이 특정된 AI가 차지한다. 크롬에서는 범용 사이드바가 이미 포화(Sider·Monica)라서 **상황 특화 + 한국 웹사이트 특화**가 빈자리다.
2. **결제·구독 불만은 모든 플랫폼 공통이다.** 숏폼 드라마, AI 구독, 크롬 AI 확장 모두 '해지 어려움·숨은 과금'이 1~2점 리뷰의 큰 축이다. 반대로 말하면 **"명확한 가격, 쉬운 해지, 로컬 처리"만으로도 차별화**가 된다.
3. **모바일에서 불편한 '문서·편집' 작업은 PC 브라우저로 옮겨갈 여지가 있다.** Notion 모바일 편집 버그(1~2점 219건 중 오류 123건), 유니브 AI 맥 앱 미작동, HWP·PDF 뷰어 앱의 광고·권한 남용이 그 근거다.
4. **숏폼 피로가 수요로 드러났다.** 카카오톡 '숏폼 강제' 불만, SocialLite(릴스·쇼츠 차단)의 한·미 생산성 상위권 진입, Cat Gatekeeper(30만, 1년 내 등록), 미국 BePresent가 같은 방향을 가리킨다.

## ⑤ 한계와 다음 단계

**한계**
- **1회 스냅샷**이라 '급상승'은 출시일과 한·미 비교로 대신 추정했다. 광고빨 반짝 순위(예: 은행 앱 교체, 이벤트성 앱)와 진짜 트렌드는 **2주 이상 누적 수집 후** `diff_report.py`로 걸러야 한다.
- iTunes RSS는 limit=200을 지정해도 **카테고리당 최대 100개**만 반환한다. 구글플레이 한국 유료 차트는 14개만 반환됐다.
- 구글플레이 차트에는 출시일이 없다. '신규' 판단은 앱스토어 releaseDate에만 의존한다.
- 크롬 웹스토어 카테고리 페이지는 **초기 렌더 32개만** 수집했다(무한스크롤 미수집). 웹스토어 기본 정렬은 '추천'이라 엄밀한 인기순·급상승 순위가 아니다. 사용자 수는 웹스토어 표기값이라 반올림돼 있다.
- 불만 분류는 **키워드 사전 방식**이다. 오탐이 있고(예: 당근의 '제한'이 AI 품질로 분류됨), '기타·불명확' 비율이 앱 27%, 크롬 42%다. 정밀 분석이 필요하면 LLM 분류로 바꿀 것을 권한다.
- 크롬 리뷰는 영어가 95%이고, 최근 1년 이내 작성은 38%다. 앱 리뷰는 최근 수개월 위주다.

**다음 단계**
1. `run_daily.bat`를 작업 스케줄러에 등록해 14일 이상 누적한 뒤 '2주 유지 신규 앱' 목록을 확정한다.
2. 아이디어 1~3에 대해 경쟁 확장 상세 페이지(가격·권한·업데이트 주기)와 한국어 리뷰를 추가로 수집한다.
3. 크롬 카테고리 페이지 무한스크롤 수집을 playwright로 확장하고, 일별 순서 변화로 '급상승'을 정의한다.
4. 1~2점 리뷰를 LLM으로 재분류해 '요청 기능' 문장만 추출하고, 이를 기능 백로그로 정리한다.

## ⑥ 재실행 / 매일 자동수집 방법

폴더 구조
```
03_앱_크롬확장_순위분석/
  scripts/
    gplay.py              구글플레이 차트·리뷰 수집 모듈(batchexecute 직접 호출)
    gplay_list_body.tpl   구글플레이 차트 요청 본문 템플릿
    daily_collect.py      앱스토어(마케팅RSS+iTunes RSS)·구글플레이 순위 → data/app_ranks.sqlite (ranks 테이블)
    diff_report.py        누적 DB로 신규 진입 / 이탈 / 14일 유지 리포트 → data/diff_report_YYYY-MM-DD.md/.csv
    analyze_ranks.py      Top30, 최근 출시 앱, 한·미 비교, 카테고리 Top10, AI 앱 집계 → data/analysis_*.csv
    app_reviews.py        주요 앱 리뷰 수집 + 불만 분류 → data/app_*_YYYY-MM-DD.csv
    chrome_collect.py     크롬 웹스토어 목록(카테고리·컬렉션·검색) + 1~2점 리뷰 → data/chrome_*.csv, chrome_ext 테이블
    analyze_chrome.py     크롬 카테고리 통계·신규 확장·불만 분류
    complaint_taxonomy.py 불만 유형 키워드 사전(수정해서 재분류 가능)
    run_daily.bat         매일 실행 배치
  data/  raw/YYYY-MM-DD/*.json(원본), app_ranks.sqlite, *.csv, 로그
```

수동 실행 (PowerShell 또는 cmd에서 `scripts` 폴더로 이동 후)
```
set PYTHONIOENCODING=utf8
python daily_collect.py               # 약 3~5분, 요청 간 1.5초 sleep
python diff_report.py --top 100 --hold-days 14
python analyze_ranks.py 2026-10-09
python app_reviews.py                 # 약 5분
python chrome_collect.py              # 목록 약 2분 + 리뷰 약 10분 (리뷰 제외: --no-reviews, 리뷰만: --reviews-only)
python analyze_chrome.py 2026-10-09
```

매일 자동 수집 (Windows 작업 스케줄러)
```
schtasks /Create /SC DAILY /ST 09:00 /TN "TrendAppRanks" /TR "\"G:\내 드라이브\100_AI개발\200_개발\20261009_최근트랜드동향파악하기\03_앱_크롬확장_순위분석\scripts\run_daily.bat\""
```
- `diff_report.py` 판정 기준: **신규** = 최근 30일 동안 같은 차트 Top100에 없다가 최신일에 등장. **2주 유지** = 첫 등장 후 14일 이상 지났고 그 뒤 수집일의 80% 이상 잔류(첫 수집일부터 있던 앱은 '기존 강자'로 제외). **이탈** = 직전 수집일엔 있었고 최신일엔 없음.
- 사내망 SSL 프록시 환경을 위해 `truststore`(윈도우 인증서 저장소)를 사용한다. 로그인·폼 제출 없이 공개 데이터만 조회한다.
