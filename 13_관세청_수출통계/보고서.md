## ④ 사업·커리어·투자 시사점

**투자('확인해볼 것' 목록, 매수·매도 권유 아님)**
- 반도체: 9월 잠정 반도체 605억달러(+260%). 3분기 실적 시즌에 SK하이닉스·삼성전자 실적이 이 속도와 맞는지 확인하고, 10월 1~10일 잠정치(10/11경)로 4분기 초입 흐름을 확인.
- 화장품: 실리콘투는 폴란드보다 **캐나다·영국·네덜란드**가 더 빠르게 늘고 있음. 회사가 밝히는 지역별 매출과 비교해 볼 것. 에이피알·코스맥스도 같은 표로 확인.
- 라면: 삼양식품은 미국 둔화(+10%)를 중국·유럽·멕시코가 메우는지가 관건. 다음 분기 해외 매출의 지역 구성을 확인.
- 전력기기: 초고압 변압기는 3개월로 보면 제자리라 '수출 급증' 이야기는 이미 숫자에 반영된 상태일 수 있음. 미국 월별 선적(8월 9,850만달러)과 말레이시아 신규 수요를 수주잔고와 대조. 전선(LS·대한전선)은 미국향 +40%로 변압기보다 강함.
- 2차전지: 미국향 수출 -25%. 수출 감소가 '현지 생산 전환' 때문인지 '수요 둔화' 때문인지 미국 공장 가동률로 구분해 볼 것.
- 방산: 폴란드향 인도가 계속 잡힘. 현대로템·한화에어로스페이스·풍산은 분기 인도 일정과 수출 통계가 같이 움직이는지 확인.

**사업(크롬확장·자동화 도구)**
- 이번에 쓴 tradedata.go.kr 조회는 로그인 없이 품목×국가×월 데이터를 몇 초 만에 줌. **"관심 HS코드 넣으면 매월 국가별 급증 알림"**을 주는 크롬확장이나 텔레그램 봇은 중소 수출기업·K뷰티 셀러·주식 투자자 모두에게 쓸모가 있음(공공데이터 기반이라 데이터 비용 0).
- 10일 잠정치 공개일(매월 11일·21일·다음 달 1일경)에 맞춰 자동 요약을 보내는 것만으로도 차별화 가능.

**커리어(금융보안·컴플라이언스)**
- 방산·전력기기·반도체 수출이 특정 국가로 크게 늘면서 **수출통제·전략물자·제재국 우회 수출 점검** 수요가 커짐(예: 키르기스스탄·카자흐스탄향 승용차는 줄었지만 여전히 3개월 6.5억달러 수준). 무역 통계로 '이상한 국가별 급증'을 찾는 방법은 AML·무역금융 모니터링(TBML)에도 그대로 쓸 수 있음.

## ⑥ 재실행 방법

```
cd 13_관세청_수출통계
python -I -X utf8 scripts\collect.py          # 보고서용 전체 수집 → data\raw (약 2분)
python -I -X utf8 scripts\analyze.py          # 표 계산 → data\processed + 화면 출력
python -I -X utf8 scripts\daily_update.py     # 일일 갱신 → data\snapshots\YYYYMMDD\ (meta.json=완료)
python -I -X utf8 scripts\daily_update.py --force   # 새 데이터 없어도 다시 분석
python -I -X utf8 scripts\telegram_summary.py # 최신 스냅샷 요약(네트워크 없음)
```

- daily_update는 매일 잠정치·월별 최신 월만 가볍게 확인(약 20초)하고, **새 잠정치 구간이나 새 달 확정치가 있을 때만** 다시 분석. 없으면 직전 summary를 그대로 쓰고 meta.json에 `data_updated=false, kept_from=직전날짜`를 남김. 새 달 확정치가 나오면 품목 15개×25개월을 받음(약 1~2분, 캐시 `data\snapshots\monthly_cache\YYYYMM.csv.gz`).
- 필요한 키: 없음(선택: 공공데이터포털 「관세청_품목별 국가별 수출입실적(GW)」 활용신청. 같은 MOLIT_API_KEY 사용).
- 관심 품목·관련 상장사는 `scripts\common.py`의 `ITEMS`에서 수정.
